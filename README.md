# Student Placement Prediction

## 📌 Overview
A machine learning project that predicts student placement outcomes based on academic and personal metrics. Uses Python with NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn for data analysis and model training.

## 🎯 Features
- Student data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature encoding and scaling
- Placement prediction model
- Interactive web application
- Visualization of key metrics

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Streamlit/Flask
- Joblib

## 📂 Project Structure
- `student_place.ipynb` - Complete analysis notebook
- `app3.py` - Web application for predictions
- `placement_model_artifacts.pkl` - Trained model
- `student_placement_salary_elite_v2.csv` - Training dataset
- `requirements.txt` - Dependencies

## 🚀 Installation
```bash
pip install -r requirements.txt
```

## 💻 Usage
Run the web application:
```bash
python app3.py
```

## 📊 Dataset
- Student academic records
- Placement status
- Salary information
- Internship details
- Technical skills

## 🎯 Prediction Features
The model predicts:
- Placement likelihood
- Expected salary range
- Job sector placement
- Career prospects

## 📈 Model Performance
- High accuracy classification
- Balanced precision and recall
- Handles class imbalance
